# Go packages

A set of common reusable packages.

## Packages

- [errmux](./errmux) (Go 1.22+) error-returning router built on `net/http`'s `ServeMux`.
- [httpreq](./httpreq) (Go 1.27+) small generic helpers for common HTTP API requests.
- [secret](./secret) (Go 1.22+) small crypto helpers for tokens, codes, hashes, signatures, encryption, and signed URLs.
- [totp](./totp) (Go 1.22+) RFC 6238 one-time passwords and authenticator enrollment.
